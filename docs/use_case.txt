A new CNC system in an industrial production environment requires monitoring.
A "target file" (database, CSV, Excel, ODF) is created, specifying how the system is to operate.
The system provides the actual data.
The files are compared using the application.
Functionality must be implemented to attach notes and documents to the comparison results.
The comparison process (and the application itself) must meet the requirements of rigorous industrial audits.
The goal is to support quality assurance.
